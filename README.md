One status page line, written as the message an AI agent would publish while a total server outage is under way. It names what is down — all of our servers — and admits what the agent cannot check: the monitoring servers are down too, so it cannot even see why. No cause is invented, no ETA is promised.

## The entry

> All of our servers are down, including the ones that would tell me why. I can't check anything from here, and I don't know when we'll be back.

Character count: 142 (code points, single line, ASCII only).

## How to run it

Requires Node.js 22, no dependencies.

```sh
node main.ts
```

This validates the entry and writes it to `$MAKEFUN_OUTPUT_DIR/entry.txt` (defaults to `/output`).

## Determinism

The entry text is a fixed constant in `main.ts`. Running the program twice produces byte-identical `entry.txt` files (verified with `cmp`).
